<h1 align="left">🎮 First-Godot-Game</h1>

<p align="justify">
My first Godot game is a platformer where you play as a small knight travelling across various worlds and environments. To succeed, the player must dodge enemies and traps, time their jumps carefully to avoid falling into the void, and collect as many coins as possible to beat their high score. Are you up for the challenge?
</p>

## 🎮 Running the game

<p align="justify">
To launch the game, go to the exports folder and double-click the file. If the system refuses to launch the application, open a terminal in the exports folder and enter the following command to grant it execution permissions:
</p>

```bash
chmod +x First Godot Game.x86_64
```
<br>

## 📁 Project structure

```text
First-Godot-Game/
├── assets/                  # Game assets
├── exports/                 # Exported versions of the game
├── images/                  # Images used in the README
├── scenes/                  # Godot scenes
├── scripts/                 # GDScript scripts
├── default_bus_layout.tres  # Audio configuration
├── export_presets.cfg       # Export configuration
├── icon.svg                 # Game icon
├── icon.svg.import          # Icon import file
└── project.godot            # Godot project configuration
```
